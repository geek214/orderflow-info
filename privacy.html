OrderFlow Gmail Approval 隐私政策

更新日期：2026-11-01。应用仅供维护者本人使用。此说明不表示应用已获得 Google 验证。

读取的数据与用途

应用请求 Gmail 只读权限（gmail.readonly）和发送权限（gmail.send）。程序可读取账号资料、邮件元数据及正文，用于确认邮箱身份、发送通知、核对送达以及识别订单审批回复；不请求修改或删除邮件的权限。

审批检索会筛选最近 30 天的已发送邮件。处理内容可能包括发件人、收件人、主题、邮件及线程标识、时间和纯文本正文。程序不下载邮件附件，也不将正文中出现的任意肯定用语当作订单授权。

存储与第三方服务

本机 OAuth 凭据使用当前 Windows 用户绑定的 DPAPI 加密，并限制文件访问权限。经维护者单独批准的云端部署使用 GitHub Actions Secrets 托管所需凭据，GitHub 及 Google 将按照各自政策处理相应服务数据。

通知、订单状态、审批结果和必要审计记录保存在维护者控制的本机数据库或私有 GitHub 账本分支中。公开说明站点不保存这些数据。当前自动工作流不向大模型服务传送 Gmail 邮件正文；新增数据用途或接入其他处理方须事先另行审查和授权。

限制与控制

程序不出售邮件数据，不将邮件用于广告定向或模型训练。OAuth 凭据不写入源码、公开网页或普通日志。上述保护不代表任何系统能够承诺绝对安全。

维护者可在 Google 账号的第三方连接设置中撤销应用授权，在 GitHub 中停用工作流并移除相关 Secrets，也可暂停本机控制器。停止服务后，可按照维护者决定删除本机数据及私有仓库记录；Git 历史、备份和服务商保存的数据须按各自恢复及保留规则处理，不能假定删除工作区文件就已清除全部副本。

联系与变更

请通过维护者 GitHub 主页联系维护者。此页面不提供面向公众的邮箱授权或数据收集入口。用途变化时，将更新本政策并在需要时重新取得授权。
